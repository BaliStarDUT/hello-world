# OneClassSVM 简要解析
OneClassSVM（单类支持向量机）是支持向量机（SVM）算法的一个重要变种，核心用途是**无监督异常检测**——即仅使用“正常样本”训练模型，后续识别与正常模式偏离的“异常样本”，无需依赖异常样本的标注数据。


## 1. 核心思想：从“二分类”到“单类边界学习”
传统SVM用于二分类，通过寻找最优超平面分隔两类样本；而OneClassSVM的目标是：  
在高维特征空间中，学习一个**紧凑的“边界”**，将所有正常样本包裹在边界内部，边界外的样本则判定为异常。  
为实现这一目标，它引入了两个关键设计：
- **核函数（Kernel Function）**：将低维线性不可分的样本映射到高维空间，使其可分（常用RBF高斯核，适配多数复杂数据分布）。
- **ν参数（Nu Parameter）**：控制两个关键指标的平衡——① 边界内正常样本的比例（ν越接近1，允许被判定为异常的正常样本越少）；② 支持向量的数量（影响模型复杂度）。


## 2. 核心目标：最小化“异常区域”
OneClassSVM的优化目标是：  
找到一个高维空间中的“超球体”（对应低维空间的复杂边界），让这个超球体的**体积最小**（确保边界紧凑，减少误判），同时尽可能将正常样本包含在球内（允许少量正常样本落在球外，由ν参数控制比例）。


## 3. 适用场景与特点
### 适用场景
- 数据集中**异常样本极少或难以标注**（如工业设备故障检测、金融欺诈识别、网络入侵检测）；
- 仅能获取“正常模式”数据（如正常的用户行为日志、无故障的设备传感器数据）。

### 优势
- 对高维数据适应性强（依赖核函数处理维度灾难）；
- 无需异常样本，仅用正常数据即可训练，降低标注成本。

### 局限性
- 对**参数敏感**（尤其是RBF核的“gamma”参数和ν参数，需调优避免过/欠拟合）；
- 对**大规模数据效率较低**（训练过程依赖支持向量计算，数据量过大会导致速度变慢）；
- 对“正常样本分布不均匀”的场景鲁棒性较弱（易将正常但稀疏的样本误判为异常）。


## 4. 关键参数（以Scikit-learn实现为例）
| 参数       | 作用                                                                 |
|------------|----------------------------------------------------------------------|
| `kernel`   | 核函数类型，默认`rbf`（高斯核），适用于非线形分布数据；也可选`linear`（线性核）等。 |
| `nu`       | 控制“允许落在边界外的正常样本比例”，取值范围(0,1]，默认0.5。         |
| `gamma`    | RBF核的带宽参数，控制核函数的“影响范围”，过小易欠拟合，过大易过拟合。 |


## 5. 简单工作流程
1. 数据准备：收集并预处理“纯正常样本”数据（无异常标注）；
2. 模型训练：用正常样本训练OneClassSVM，学习正常样本的边界；
3. 异常判定：输入新样本，模型计算其与“正常边界”的距离——落在边界外则判定为异常。
