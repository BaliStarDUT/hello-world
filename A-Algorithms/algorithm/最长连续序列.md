## 代码解析：`longestConsecutive`

### 算法核心思想
使用**哈希集合**实现O(n)时间复杂度的最长连续序列查找，避免排序带来的O(n log n)复杂度。

### 详细执行流程

```python
def longestConsecutive(nums):
    # 去重并转为集合，O(1)查找
    nums = set(nums)
    max_length = 0  # 存储最长序列长度
    
    for num in nums:
        # 关键优化：只处理序列的起点
        if num - 1 not in nums:
            current_num = num
            current_streak = 1
            
            # 向后扩展序列
            while current_num + 1 in nums:
                current_num += 1
                current_streak += 1
            
            # 更新最大值
            max_length = max(max_length, current_streak)
    
    return max_length
```

### 关键优化点

#### 1. **起点判断策略**
```python
if num - 1 not in nums:
```
- **目的**：只处理每个连续序列的起点
- **效果**：避免重复计算，确保每个序列只处理一次
- **示例**：对于序列 `3,4,5`，只从3开始计算，跳过4和5

#### 2. **集合去重**
```python
nums = set(nums)
```
- **作用**：去除重复元素
- **优势**：O(1)时间复杂度的查找

**输入**：`[100, 4, 200, 1, 3, 2]`

**执行过程**：
