跳表数据结构介绍
跳表（Skip List）是一种**有序数据结构**，通过在原始链表基础上增加“索引层”实现快速查找，兼顾了链表的插入灵活性和数组的随机访问效率。它的核心思想是“空间换时间”，通过多级索引减少查询时的比较次数，平均时间复杂度可达到 **O(log n)**，且实现复杂度低于平衡树（如红黑树）。


### 一、跳表的结构组成
跳表由**多层链表**构成，底层是原始的有序链表（第 0 层），上层是对下层的“稀疏索引”，每层节点包含指向同一层下一个节点和下一层对应节点的指针。

#### 示例结构（存储有序数据 [1,3,5,7,9]）：
```
第 2 层：1 ---------------------> 9  （间隔最大的索引）
第 1 层：1 ---------> 5 ---------> 9  （中等间隔索引）
第 0 层：1 -> 3 -> 5 -> 7 -> 9       （原始链表，每个节点都存在）
```
- 每一层都是有序链表（按 key 升序）。
- 上层节点是下层节点的子集（如第 2 层的节点一定在第 1 层和第 0 层中存在）。
- 最底层（第 0 层）包含所有数据节点，是完整的有序链表。


### 二、核心操作原理

#### 1. 查找（Search）
从最高层索引开始，逐步向下层查找，通过索引“跳跃”过无关节点，减少比较次数：
- 从顶层（如第 2 层）的头节点出发，比较当前节点的下一个节点值：
  - 若下一个节点值 ≤ 目标值，移动到下一个节点；
  - 若下一个节点值 > 目标值，下降到下一层继续查找；
- 重复上述过程，直到到达第 0 层，找到目标节点或确认不存在。

**示例**：查找值 7  
- 第 2 层：1 的下一个节点是 9（9>7），下降到第 1 层；  
- 第 1 层：5 的下一个节点是 9（9>7），下降到第 0 层；  
- 第 0 层：5 → 7（找到目标）。  


#### 2. 插入（Insert）
- 先通过查找确定插入位置（类似链表插入）；  
- 核心：**随机决定新节点的“层数”**（通过“抛硬币”算法，如 50% 概率增加一层，直到概率失效或达到最大层数）；  
- 在所有 ≤ 新节点层数的索引层中插入该节点，并更新前后节点的指针。

**随机层数的意义**：保证索引分布均匀，避免层级过高导致性能退化。


#### 3. 删除（Delete）
- 先查找目标节点，记录所有层级中该节点的位置；  
- 从最高层到第 0 层，依次删除该节点，并更新前后节点的指针（若某层因删除节点导致头节点无后续节点，可删除该层）。


### 三、时间复杂度与空间复杂度
- **查找/插入/删除**：平均 **O(log n)**，最坏 **O(n)**（极端情况下索引分布不均，退化为单链表）。  
- **空间复杂度**：平均 **O(n)**（索引层总节点数约为 n，与原始数据规模相当）。  


### 四、跳表的优势与适用场景
#### 优势：
1. **实现简单**：相比红黑树、AVL 树的复杂旋转操作，跳表的插入/删除逻辑更直观。  
2. **并发友好**：可通过锁粒度控制（如只锁定修改的索引层）实现高效并发，而平衡树的旋转操作可能需要锁定整个树。  
3. **范围查询高效**：支持从某个节点开始，快速遍历连续区间（如查找 [5, 9] 之间的所有元素）。

#### 适用场景：
- 有序数据的高频查询、插入场景（如数据库索引、缓存系统）。  
- 需高效范围查询的场景（如 Redis 的 `zset` 底层实现之一）。  
- 并发环境下的有序数据存储（相比平衡树更容易实现线程安全）。


### 五、与其他有序结构的对比
| 结构       | 平均查找 | 实现复杂度 | 并发友好性 | 范围查询 |
|------------|----------|------------|------------|----------|
| 跳表       | O(log n) | 低         | 高         | 高效     |
| 红黑树     | O(log n) | 高         | 低         | 高效     |
| 有序数组   | O(log n) | 低         | 中         | 高效     |
| 单链表     | O(n)     | 极低       | 中         | 低效     |


### 六、简单实现（Python 示例）
```python
import random

class SkipListNode:
    def __init__(self, key, value, level):
        self.key = key
        self.value = value
        self.forward = [None] * (level + 1)  # 存储各层的下一个节点

class SkipList:
    def __init__(self, max_level=16, p=0.5):
        self.max_level = max_level  # 最大层数
        self.p = p  # 增加层数的概率
        self.level = 0  # 当前最高层数
        self.header = SkipListNode(-1, None, max_level)  # 头节点

    # 随机生成节点层数
    def _random_level(self):
        level = 0
        while random.random() < self.p and level < self.max_level:
            level += 1
        return level

    # 插入键值对
    def insert(self, key, value):
        update = [None] * (self.max_level + 1)  # 记录各层需要更新的节点
        current = self.header

        # 从顶层向下查找插入位置
        for i in range(self.level, -1, -1):
            while current.forward[i] and current.forward[i].key < key:
                current = current.forward[i]
            update[i] = current  # 记录当前层的前驱节点

        # 生成随机层数
        new_level = self._random_level()
        if new_level > self.level:
            for i in range(self.level + 1, new_level + 1):
                update[i] = self.header
            self.level = new_level

        # 创建新节点并插入各层
        new_node = SkipListNode(key, value, new_level)
        for i in range(new_level + 1):
            new_node.forward[i] = update[i].forward[i]
            update[i].forward[i] = new_node

    # 查找键对应的值
    def search(self, key):
        current = self.header
        for i in range(self.level, -1, -1):
            while current.forward[i] and current.forward[i].key < key:
                current = current.forward[i]
        current = current.forward[0]
        if current and current.key == key:
            return current.value
        return None

    # 删除键
    def delete(self, key):
        update = [None] * (self.max_level + 1)
        current = self.header

        # 查找并记录各层前驱节点
        for i in range(self.level, -1, -1):
            while current.forward[i] and current.forward[i].key < key:
                current = current.forward[i]
            update[i] = current

        current = current.forward[0]
        if not current or current.key != key:
            return False  # 键不存在

        # 从各层删除节点
        for i in range(self.level + 1):
            if update[i].forward[i] != current:
                break
            update[i].forward[i] = current.forward[i]

        # 更新最高层数
        while self.level > 0 and self.header.forward[self.level] is None:
            self.level -= 1
        return True
```


### 总结
跳表通过“多级索引”和“随机层数”机制，在保持链表灵活性的同时，实现了接近平衡树的查询效率，且实现简单、并发友好，是很多中间件（如 Redis、LevelDB）的核心数据结构之一。
