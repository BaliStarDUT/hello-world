### 一、基础数据结构类（入门必掌握）
#### 1. 两数之和（LeetCode 1）
**题目描述**：给定一个整数数组 `nums` 和一个目标值 `target`，请你在该数组中找出和为目标值的那两个整数，并返回它们的数组下标（假设每种输入只对应一个答案，且数组中同一个元素不能使用两次）。  
**示例**：输入 `nums = [2,7,11,15]`，`target = 9`，输出 `[0,1]`。  

**解题思路**：  
- 暴力法（O(n²)）：双层循环遍历，找 `nums[i] + nums[j] = target`，但效率低，面试中不推荐；  
- 哈希表（O(n)）：遍历数组时，用哈希表存储“数值→下标”，对每个 `nums[i]`，检查 `target - nums[i]` 是否在哈希表中，存在则返回下标，不存在则存入当前数值和下标。  

**关键考点**：哈希表的“空间换时间”思想，数组遍历的优化。


#### 2. 反转链表（LeetCode 206）
**题目描述**：给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表头节点。  
**示例**：输入 `1→2→3→4→5`，输出 `5→4→3→2→1`。  

**解题思路**：  
- 迭代法（O(n) 时间，O(1) 空间）：用 `prev`（前驱节点）、`curr`（当前节点）、`nextTemp`（临时存储下一个节点）三个指针，遍历链表时依次反转 `curr` 的指向（`curr.next = prev`），再更新三个指针；  
- 递归法（O(n) 时间，O(n) 空间）：递归到链表末尾（base case：`head == null` 或 `head.next == null`），然后从末尾开始反转，`head.next.next = head`，`head.next = null`，返回新的头节点。  

**关键考点**：链表的指针操作，递归的“递推+回溯”逻辑，空间复杂度优化。


#### 3. 二叉树的层序遍历（LeetCode 102）
**题目描述**：给你二叉树的根节点 `root`，返回其节点值的层序遍历（即逐层地，从左到右访问所有节点）。  
**示例**：输入根节点 `1`（左子树 `2`，右子树 `3`；`2` 有左子树 `4`），输出 `[[1],[2,3],[4]]`。  

**解题思路**：  
- BFS（广度优先搜索）：用队列存储每一层的节点，遍历队列时，先记录当前层的节点数 `levelSize`，再循环 `levelSize` 次取出节点，将节点值加入当前层列表，同时把左右子节点加入队列，最后将当前层列表加入结果。  

**关键考点**：BFS的队列应用，树的层级遍历逻辑，边界处理（空树、单节点树）。


### 二、算法思想类（高频核心）
#### 4. 最长递增子序列（LeetCode 300）
**题目描述**：给你一个整数数组 `nums`，找到其中最长严格递增子序列的长度（子序列不要求连续，如 `[3,6,2,7]` 的最长递增子序列是 `[3,6,7]`，长度3）。  

**解题思路**：  
- 动态规划（O(n²) 时间，O(n) 空间）：  
  1. 定义 `dp[i]` 为“以 `nums[i]` 结尾的最长递增子序列长度”，初始值 `dp[i] = 1`（每个元素自身是子序列）；  
  2. 遍历 `i` 从1到n-1，再遍历 `j` 从0到i-1，若 `nums[j] < nums[i]`，则 `dp[i] = max(dp[i], dp[j] + 1)`；  
  3. 最终结果是 `dp` 数组的最大值。  
- 贪心+二分查找（O(n log n) 时间，O(n) 空间）：  
  1. 维护一个 `tails` 数组，`tails[k]` 表示“长度为k+1的递增子序列的最小尾元素”；  
  2. 遍历 `nums`，对每个元素 `x`，若 `x > tails[-1]` 则加入 `tails`，否则用二分查找找到 `tails` 中第一个 ≥x 的位置，替换为x；  
  3. `tails` 的长度即为最长递增子序列的长度（适合n较大的场景）。  

**关键考点**：动态规划的状态定义与转移方程，贪心+二分的优化思路，子序列与子数组的区别。


#### 5. 岛屿数量（LeetCode 200）
**题目描述**：给你一个由 `'1'`（陆地）和 `'0'`（水）组成的二维网格，请你计算网格中岛屿的数量（岛屿是由相邻的陆地连接而成，相邻指上下左右，斜向不相邻）。  
**示例**：输入网格  
```
11110
11010
11000
00000
```
输出 `1`。  

**解题思路**：  
- DFS（深度优先搜索）：  
  1. 遍历网格的每个单元格，若遇到 `'1'`（未访问过的陆地），则岛屿数量+1，同时触发DFS；  
  2. DFS中，将当前单元格标记为 `'0'`（避免重复访问），再递归遍历上下左右四个方向的单元格，遇到 `'1'` 则继续DFS。  
- BFS（广度优先搜索）：逻辑与DFS类似，只是用队列存储待访问的陆地单元格，依次取出并标记，再加入相邻的陆地单元格。  

**关键考点**：二维网格的遍历，DFS/BFS的应用（连通分量统计），访问标记的技巧（直接修改原网格或用额外矩阵）。


#### 6. 无重复字符的最长子串（LeetCode 3）
**题目描述**：给定一个字符串 `s`，请你找出其中不含有重复字符的最长子串的长度。  
**示例**：输入 `s = "abcabcbb"`，输出 `3`（最长子串是 `"abc"`）。  

**解题思路**：  
- 滑动窗口（双指针+哈希表，O(n) 时间）：  
  1. 用 `left`（窗口左边界）、`right`（窗口右边界）表示当前无重复子串的范围，用哈希表存储“字符→最近出现的下标”；  
  2. 遍历 `right` 从0到n-1，若 `s[right]` 在哈希表中且下标 ≥ `left`（说明字符在当前窗口内重复），则更新 `left` 为 `哈希表[s[right]] + 1`；  
  3. 用哈希表更新 `s[right]` 的最新下标，同时计算当前窗口长度 `right - left + 1`，并更新最大值。  

**关键考点**：滑动窗口思想（双指针的动态调整），哈希表的辅助作用，子串（连续）与子序列的区别。


### 三、进阶综合类（中高级面试）
#### 7. 合并K个升序链表（LeetCode 23）
**题目描述**：给你一个链表数组，每个链表都已经按升序排列，请你将所有链表合并到一个升序链表中，返回合并后的链表。  
**示例**：输入 `lists = [[1,4,5],[1,3,4],[2,6]]`，输出 `1→1→2→3→4→4→5→6`。  

**解题思路**：  
- 优先队列（小根堆，O(n log k) 时间，k是链表个数，n是总节点数）：  
  1. 初始化小根堆，将每个链表的头节点（非空）加入堆（堆按节点值排序）；  
  2. 初始化合并链表的虚拟头节点 `dummy` 和当前节点 `curr`；  
  3. 弹出堆顶节点（最小节点），将其接在 `curr` 后面，若该节点有下一个节点，则将下一个节点加入堆；  
  4. 重复步骤3，直到堆为空，返回 `dummy.next`。  
- 分治法（O(n log k) 时间）：将 `k` 个链表分成两半，递归合并左半和右半，最后合并两个升序链表（类似归并排序）。  

**关键考点**：优先队列的应用（多元素选最小），分治思想，链表的合并操作。


#### 8. 正则表达式匹配（LeetCode 10）
**题目描述**：给你一个字符串 `s` 和一个字符规律 `p`，请你来实现一个支持 `'.'` 和 `'*'` 的正则表达式匹配（`'.'` 匹配任意单个字符，`'*'` 匹配零个或多个前面的那一个元素）。  
**示例**：输入 `s = "aa"`，`p = "a*"`，输出 `true`；输入 `s = "ab"`，`p = ".*"`，输出 `true`（`.*` 匹配任意字符序列）。  

**解题思路**：  
- 动态规划（O(mn) 时间，m是s长度，n是p长度）：  
  1. 定义 `dp[i][j]` 表示“`s[0..i-1]` 与 `p[0..j-1]` 是否匹配”；  
  2. 初始化 `dp[0][0] = true`（空串匹配空串），`dp[0][j]` 需满足 `p[j-1] = '*'` 且 `dp[0][j-2] = true`（如 `p = "a*"` 匹配空串）；  
  3. 分情况讨论：  
     - 若 `p[j-1] != '*'`：若 `s[i-1] == p[j-1]` 或 `p[j-1] == '.'`，则 `dp[i][j] = dp[i-1][j-1]`；  
     - 若 `p[j-1] == '*'`：  
       - 匹配0次：`dp[i][j] = dp[i][j-2]`（忽略 `p[j-2]` 和 `*`）；  
       - 匹配1次及以上：若 `s[i-1] == p[j-2]` 或 `p[j-2] == '.'`，则 `dp[i][j] = dp[i-1][j]`（用 `*` 匹配 `s[i-1]`，继续看 `s[i-2]`）。  

**关键考点**：动态规划的复杂状态转移，正则表达式的匹配规则理解，边界条件处理（空串、`*` 的多场景）。
